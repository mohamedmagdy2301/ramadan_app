# خطة إعادة تصميم صفحة السبحة (Sabha Redesign Plan)

## الهدف
إنشاء تصميم جديد وجذاب لصفحة السبحة يشجع المستخدم على التسبيح ويوفر تجربة روحانية مميزة.

## المشاكل في التصميم الحالي
1. تصميم بسيط جداً وغير ملهم
2. الدائرة المركزية فارغة وبدون تفاصيل
3. لا توجد تأثيرات بصرية مشجعة عند التسبيح
4. لا يوجد هدف واضح للمستخدم (مثل الوصول لـ 33 أو 99)
5. عدم وجود إحصائيات أو تتبع للإنجازات

## التصميم الجديد

### 1. الخلفية المتحركة (Animated Background)
- خلفية متدرجة ناعمة بألوان إسلامية هادئة
- جزيئات نور متحركة (Particle effect) تمثل النور والروحانية
- تغير لون الخلفية بناءً على نوع الذكر المختار

### 2. الدائرة المركزية المحسنة (Enhanced Main Circle)
- **تصميم متعدد الحلقات:**
  - حلقة خارجية: تمثل التقدم نحو الهدف (33/99/مخصص)
  - حلقة وسطى: تأثير توهج (Glow) متحرك
  - المركز: عرض العداد بخط عربي جميل (Amiri)

- **تأثيرات عند الضغط:**
  - Ripple effect من المركز
  - توهج متزايد
  - اهتزاز خفيف (Haptic feedback)
  - صوت خفيف اختياري (click sound)

### 3. شريط اختيار الذكر (Dhikr Selector)
- تصميم أنيق بـ Chips أو Cards أفقية قابلة للتمرير
- كل ذكر له أيقونة أو رمز مميز
- إظهار عدد المرات المستهدفة لكل ذكر

### 4. نظام الأهداف والإنجازات (Goals & Achievements)
- أهداف محددة مسبقاً: 33، 99، 100، 1000
- هدف مخصص يحدده المستخدم
- احتفال بصري عند إكمال الهدف (Confetti/Celebration)
- عرض شارات الإنجاز

### 5. الإحصائيات السريعة (Quick Stats)
- عداد اليوم
- أكثر ذكر تم تسبيحه
- سلسلة الأيام المتتالية

### 6. أزرار التحكم (Control Buttons)
- زر إعادة التعيين مع تأكيد
- زر تغيير الهدف
- زر كتم/تفعيل الصوت
- زر مشاركة الإنجاز

| العنصر | اللون |

| خلفية رئيسية | تدرج من Primary إلى أغمق |
| حلقة التقدم | Primary مع توهج |
| نص العداد | أبيض/ذهبي |
| الأزرار | Primary مع شفافية |

## التأثيرات الحركية (Animations)

1. **عند الضغط على الدائرة:**
   - Scale animation (1.0 → 0.95 → 1.0)
   - Ripple من المركز
   - توهج يتزايد ثم يخفت

2. **حلقة التقدم:**
   - تتحرك بسلاسة مع كل ضغطة
   - تغير لونها عند الاقتراب من الهدف

3. **عند إكمال الهدف:**
   - Confetti animation
   - رسالة تهنئة منبثقة
   - اهتزاز احتفالي

4. **الجزيئات في الخلفية:**
   - حركة بطيئة ومستمرة
   - تتفاعل مع كل ضغطة

## طريقة استخدام الميزة

1. **اختيار الذكر:** التمرير أفقياً أو الضغط على الذكر المطلوب
2. **بدء التسبيح:** الضغط على الدائرة المركزية
3. **متابعة التقدم:** مشاهدة حلقة التقدم تمتلئ
4. **إكمال الهدف:** الاستمتاع بالاحتفال عند الوصول للهدف
5. **إعادة التعيين:** الضغط على زر Reset لبدء جولة جديدة
